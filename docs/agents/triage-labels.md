# Etichette di triage

| Etichetta | Significato |
| --- | --- |
| needs-triage | Idea da esaminare |
| needs-info | Servono informazioni prima di procedere |
| ready-for-agent | Specifica eseguibile; controllare anche dipendenze e stato |
| ready-for-human | Serve una decisione o verifica manuale |
| wontfix | Richiesta esclusa con motivazione |

Sono etichette del team Leochist. Non sostituiscono gli stati Linear.
Rimuovere la precedente etichetta di triage quando cambia ruolo, preservando
Bug, Feature, Improvement e altre etichette non pertinenti al triage.
